# Google Search Console

## 管理するプロパティ

`swiswiswift.com` のドメインプロパティを使用します。ブログ管理用のGoogleアカウントには既存の確認済み所有権があり、その登録を継続して利用します。

[Search Console](https://search.google.com/search-console) を開き、操作前に右上のアカウントメニューでブログ管理用のアカウントを選択してください。アカウントの番号（`/u/0/`、`/u/1/`など）はブラウザのログイン順で変わるため、URLの番号だけで判断しないでください。

「設定 → 所有権の確認」で「あなたは確認済みの所有者です」と表示されること、「ユーザーと権限」で目的のアカウントが所有者であることを確認します。

## DNSによる所有権確認

所有権確認用のTXTレコードは `cloudflare-iac/google-verification.tf` で管理しています。既存のGoogleドメイン確認にも使われるレコードなので、維持してください。

別のアカウントを追加する必要がある場合は、そのアカウントで生成した確認値をTerraformに追加し、`terraform validate`、`terraform plan`で対象レコードだけが変更されることを確認してからapplyします。

所有者を削除する場合は、引き継ぐアカウントの確認済み所有権を先に確認します。「ユーザーと権限」で削除対象の確認方法とトークンを確認し、そのアカウント専用のトークンとアクセス権を削除します。他の所有者のトークンを削除しないでください。

## サイトマップ

Hugoが生成する `https://swiswiswift.com/sitemap.xml` を「サイトマップ」画面で送信します。ドメインプロパティでは完全なURLを入力してください。

送信後は詳細画面で「サイトマップは正常に処理されました」、最終読み込み日時、検出されたページ数を確認します。送信直後の一覧では取得状態の反映に時間がかかる場合があります。

記事更新時はmainへのpushで同じURLのサイトマップも更新されます。Googleは登録済みサイトマップを定期的に取得します。

## 記事を確認する

上部のURL検査欄に公開記事の完全なURLを入力し、インデックス登録状況を確認します。過去のクロール結果と現在の配信を区別し、現在の取得状況を確認したい場合は「公開URLをテスト」を使用します。

サイトマップ送信は、すべての記事のインデックス登録や順位を保証するものではありません。
