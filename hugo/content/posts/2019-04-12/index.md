<br>

サーバーを複数管理していると間違えて異なるサーバにログインしてしまう事があります。  
ログイン時に表示したい文字は `$/etc/motd` に記述します。  
ただのテキストだと気が付きにくいので、figlet コマンドを使ってAAを作成するのがマイブームです。

### install figlet
`$ brew install figlet`

`$ figlet rikako.jp`
